## How to Add Music

1. Download 3 royalty-free soothing tracks
2. Place them in this directory with simple names:
   - `ambient.mp3`
   - `peaceful.mp3`
   - `piano.mp3`

3. (No code changes needed - the player will automatically find them!)

## Tips

- Keep files under 10MB each for better performance
- Use 128-192 kbps bitrate for good quality without large file sizes
- Test that all tracks loop smoothly
- Ensure you have proper licenses/attribution if required
